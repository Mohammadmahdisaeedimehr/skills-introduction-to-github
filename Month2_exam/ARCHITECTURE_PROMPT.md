# 15-minute architecture explanation

After the implementation is finished, explain the system in your own words without reading from the files.

Cover these points:

1. What problem does your small system solve?
2. Why did you choose these tables?
3. What relationship exists between the tables?
4. Which constraints protect data quality?
5. What does each of the five queries answer?
6. How does Python obtain the database connection?
7. Where does SQL live and why?
8. What do the tests prove?
9. What happens when invalid data is inserted?
10. If this project became 100 times larger, what would you change first?

The target is about 15 minutes. Clear reasoning matters more than terminology.
